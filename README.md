# Clínica Médica

Base web en Python + SQLite para una clínica médica.

## Arranque

1. Abre una terminal en esta carpeta.
2. Ejecuta `python server.py`.
3. Abre `http://localhost:3000`.

## Usuario inicial

- Usuario: `admin`
- Contraseña: `Admin123!`

## Módulos incluidos

- Login y roles de usuario.
- Gestión de usuarios y permisos.
- Gestión de pacientes.
- Historial clínico.
- Citas, consultas y evolución.
- Tratamientos, diagnósticos y recetas.
- Búsqueda rápida y filtros.
- Respaldo de datos y auditoría de cambios.
